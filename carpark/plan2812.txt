## 3.1 Vehicle Registration Module

### Purpose

Allow users to register vehicles before parking.

### Entity

```java
Vehicle
- id
- vehicleNumber (unique)
- vehicleType (CAR, BIKE, EV, HANDICAPPED)
- ownerId
- createdAt
```

### Pattern

* **Factory Pattern**

  * VehicleFactory creates concrete vehicle types
  * No switch-case in services

### APIs

```http
POST /api/vehicles
GET  /api/vehicles/user/{userId}
```

### Notes

* Validate vehicle number format
* Prevent duplicate registration
* Vehicle type influences:

  * Slot eligibility
  * Pricing strategy

---

## 3.2 Parking Area Registration (Admin)

### Purpose

Admin defines parking infrastructure.

### Composite Pattern Structure

```
ParkingLot
 └── ParkingFloor
      └── ParkingSlot
```

### APIs (Admin-only)

```http
POST /api/admin/parking-lots
POST /api/admin/parking-floors
POST /api/admin/parking-slots
```

### Slot Attributes

```java
ParkingSlot
- slotNumber
- slotType (COMPACT, LARGE, EV, HANDICAPPED)
- state (FREE, OCCUPIED, RESERVED, OUT_OF_SERVICE)
```

### Important Rules

* SlotType must match VehicleType
* Slot state handled via **State Pattern**
* Slot should notify observers on state change

SlotAllocationService
```

### Strategies

* NearestSlotStrategy

### Selection Criteria

* Vehicle type
* User preference
* Parking lot rules
* Admin-configured defaults

### API

GET /api/parking/slots/available?vehicleType=CAR&strategy=NEAREST
```

## 3.4 Parking Session Lifecycle (Core Flow)

### Entity

```java
ParkingSession
- sessionId
- vehicleId
- parkingSlotId
- entryTime
- exitTime
- status (ACTIVE, COMPLETED)
```

---

### Entry Flow (Template Method + Command)

```text
Vehicle arrives
→ EntryCommand
→ EntryGateProcessor.process()

Steps:
1. validateRequest()
2. fetchContext()
3. allocateSlot()
4. createSession()
5. updateSlotState(FREE → OCCUPIED)
6. notifyAvailability()
```

### API

```http
POST /api/parking/entry
```

---

### Exit Flow

```text
Vehicle exits
→ ExitCommand
→ ExitGateProcessor.process()

Steps:
1. fetchSession()
2. calculateBill()
3. applyDiscounts()
4. freeSlot()
5. closeSession()
6. notifyAvailability()
```

### API

```http
POST /api/parking/exit
```
